# 1 KB 文件编辑证明实测

两份文件均为 1024 字节（1 KiB），ASCII 编码、LF 换行、无 BOM，因此各有 1024 个 Unicode 字符。原文由 16 行、每行 64 字节组成；新文将原文偏移 512 开始的 8 个字符替换为 NOVAEDIT，长度保持不变。

从项目根目录运行：

```powershell
cargo run --release -- examples/old_1kb.txt examples/new_1kb.txt
```

Myers 输出：keep(512), delete(8), insert("NOVAEDIT"), keep(504)。每块上限为 8 字符，共 129 步；没有将总块数限制为 8。

2026-10-29 本机 release 单次运行结果（不含编译、文件读取、Myers）：

| 阶段 | 总耗时（s） | 明细（s） |
| --- | ---: | --- |
| setup | 17.586 | 公共参数 13.397；压缩密钥 4.189 |
| prove | 106.719 | 递归 87.927；压缩 18.792 |
| verify | 1.071 | 递归 0.579；压缩证明 0.492 |

计时区间总耗时 125.455 s，包含日志和负向检查。递归证明、压缩证明、完整消费检查和篡改公开输入拒绝检查均通过。

这是少量修改的单个样例，不是多轮统计，也不代表任意 1 KB 文本的性能。当前电路仍携带完整文本与操作序列，并使用线性查找。
